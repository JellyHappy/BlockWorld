# Controls and quick walkthrough

| Atari input | Action |
| --- | --- |
| Joystick 1 left/right | Move |
| Joystick 1 fire | Jump; release before next jump |
| Joystick 1 up | Build after collecting three bricks; rescue nearby friend; enter right portal |
| Reset | Return to title and clear the run |
| Select at title | Toggle solo / shared-controller relay |
| Fire at title | Start selected mode |
| Release then Fire after victory/game over | Return to title |

Start by collecting the brick on the left. Jump onto the raised platform, collect the next piece, then continue right to the last piece. Up fills the pit with a bridge. Cross it and jump onto the bot from above. After the bot changes into a friend, return to the floor, stand beside them, and press Up. At the far-right marker, press Up to travel onward.

The Fortress boss takes three stomps. Let the automatic bounce carry you above the boss and follow its patrol. Side contact costs a life. There are three lives for the entire campaign; the upper-right bar shrinks on death. The upper-left notches indicate world number.

Relay players share joystick 1 and pass it on after death. Shared score changes color on the handoff. Keyboard users can share the same arrow keys and Fire key. There is no simultaneous two-player control.
